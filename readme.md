# Audit Analytics & Risk Detection System

## 📌 Project Overview

This project focuses on building an end-to-end **Audit Analytics System** using real-world regulatory data from the U.S. Securities and Exchange Commission (SEC).

The goal is to analyze audit enforcement cases, identify fraud patterns, and generate actionable risk insights similar to those used in consulting firms.

---

## 🎯 Objectives

- Perform data cleaning and validation on audit datasets
- Analyze fraud and compliance trends using SQL
- Build risk scoring models using Python
- Identify high-risk industries and entities
- Visualize audit insights and trends
- Demonstrate scalability using PySpark

---

## 📊 Dataset

Primary dataset:

- SEC Accounting & Auditing Enforcement Releases (AAER)
- Contains real-world fraud and compliance cases

---

## 🛠️ Tech Stack
